Price Quotes — config-driven demo

Everything the engine knows comes from one plain JSON object — no code, no classes, no functions. Edit the config (the catalog, currencies, taxes, discounts, …), edit the request (what's being quoted), and the response recomputes live, entirely in your browser.

new Quotes(config).quote(request, options) — the two boxes on the left are literally that call's arguments, serialized.

Config valid

A plain QuotesConfig JSON object — catalog, currencies, rates, taxes, discounts, rounding.

Request valid

A plain JSON object: QuoteRequest fields plus an optional top-level explore flag.

Response

The exact object returned by engine.quote(), as JSON.
